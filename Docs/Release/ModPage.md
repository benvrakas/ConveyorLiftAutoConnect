# Name

Conveyor Lift Auto-Connect Plus

# Mod reference

ConveyorLiftAutoConnect

# SHORT DESCRIPTION

Auto-connects conveyor lifts between stacked blueprints, without the split chains that crash saves, and places fast.

# FULL DESCRIPTION

See `FullDescription.md`.

# SOURCE

https://github.com/benvrakas/ConveyorLiftAutoConnect

# NETWORK ACTIVITY TRANSPARENCY

This mod makes no external network connections. Multiplayer synchronization uses Satisfactory's and SML's normal
construction networking only.

# AI USAGE TRANSPARENCY

The code, documentation and release packaging were written with Anthropic Claude (Claude Code) and tested in game by
benvrakas. The icon is drawn by a script written with Claude. The mod began as a fork of ZeeOcho's Vertical Conveyor
Auto-Connect, which was developed with OpenAI ChatGPT; parts of its documentation and test blueprints remain.
